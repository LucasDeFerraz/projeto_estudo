Termos e Condições

Este é um projeto de estudo de frontend. O preenchimento serve apenas para demonstração e não realiza uma matrícula em uma escola.

Utilize somente dados fictícios. Os termos de uma escola real precisariam ser definidos antes de disponibilizar este formulário para uso real.

Política de Privacidade

Esta demonstração não envia os dados do formulário nem os arquivos selecionados para um servidor. Ao salvar respostas, um rascunho é baixado apenas no seu dispositivo.

O rascunho contém os campos preenchidos, mas não inclui os anexos. Use dados fictícios e evite inserir informações pessoais ou médicas reais.
